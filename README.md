#### Things I built

- **[notas](https://github.com/ju1010/notas)** — a local notes app with a native window

  folded block, search across titles, tags and body. No cloud, no account, no internet.
- **[Aster](https://github.com/ju1010/Aster)** — a personal finance manager: a NestJS API with

- **[uptime-monitor](https://github.com/ju1010/uptime-monitor)** — a service that checks a list
  of URLs on a schedule, stores the results and notifies when something goes down.
